# Chukwudubem Osegbe — Portfolio

The source for [osegbe.com](https://osegbe.com), my personal portfolio covering software engineering, infrastructure, NIPPYSKY ventures and my growing AI/ML practice.

Built with Next.js, React, TypeScript and Sanity. Includes selected work, experience, education and an automatically updated AI, ML & Automation Lab. Full company case studies live at [NIPPYSKY](https://nippysky.com).

The website lives in `app/`; the Sanity Studio lives in `backend/`.

Lab synchronization runs separately in the private `nippysky-ai-labs/portfolio-sync` repository. This website reads the published content from Sanity.
