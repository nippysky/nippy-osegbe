# Portfolio Studio

The Sanity content editor for [osegbe.com](https://osegbe.com). It manages the profile, selected work, experience, education, CV and AI & Automation Lab presentation.

Uses the `vuye8s8l` project and `production` dataset. Run `npm run dev` here to open the editor locally. Run `npm run deploy` after changing Studio schemas, configuration or dependencies. Publishing content does not require a deployment.
